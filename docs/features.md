# 功能

Ballast 0.1.0 的功能边界是“有新增资金、不卖出、按整手买入”。以下功能都能用示例数据在本地复现。

## 组合与目标

- 首次设置：组合名称、基础币种、三分类或单分类模板。
- 分类目标：目标比例、偏离带；保存时校验合计 100.00%。
- 账户：可新增、改名、归档；最后一个未归档账户不能删。

## 持仓与价格

- 代码：ticker、名称、分类、每手份数、现价、价格日期；归档/恢复。
- 成交：手工买入/卖出，按账户+代码计算持仓和平均成本。
- 价格：单个更新或最多 200 项批量更新；价格只影响市值，不改变成交记录。
- CSV：模板下载、导入、交易导出、持仓导出；导入整体成功或整体失败。

## 买入计划

- 输入投入金额、最小单笔金额。
- `greedy-v1`：目标后总市值 → 分类目标 → 缺口 → 分类预算 → 分类内按市值分配 → 整手取整 → 残值再分配 → 最小单笔过滤。
- 输出买入项、分类买入前后偏离、最大偏离、警告、剩余现金。
- 计划保存输入哈希；价格、持仓、目标、分类顺序、代码归档/手数/ticker 变化后执行返回 409。
- 执行只写入一个账户，事务内生成 `source=plan` 交易；计划状态和执行时间保留。

## 数据与安全

- SQLite 单文件，WAL、外键、迁移表、迁移前自动备份。
- 只监听回环（Docker 容器例外见 `docs/deploy.md`），写请求 Origin/Content-Type 校验。
- 无外部 API、无遥测、无 CDN 字体/图标/图表。
- 备份下载、示例模式与恢复。

## 明确没有

行情、券商同步、自动交易、卖出建议、税务/成本匹配、多币种、登录、多用户、云同步、移动 App、收益归因、LLM 建议、短仓/杠杆/期权/加密货币精度。
