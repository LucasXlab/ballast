# 决定记录

- 许可证：MIT。理由：本地个人工具、无托管服务，宽松许可便于审计和采用；发布前在 `notes/许可证.md` 补完整理由。
- 日期时区：统一 UTC。避免 Docker 默认 UTC 与浏览器本地时区造成“今天+1”差一天。
- 持仓展示：按账户+代码聚合；计划按代码再汇总全组合，执行时写入单一账户。
- 分类目标：编辑过程中总和可小于 10000；`PUT /api/targets` 和生成计划要求恰好 10000。
- 计划执行过期：只比较 `inputsHash`；价格清空也归类为 `plan_stale`，不再单独报 `missing_price`。
- 计划买入后偏离：分母用 `total + planned`，不用 `total + amount`；整手限制可能让偏离变大，用 `drift_worsened` 警告。
- 导入不可撤销：不提供撤销接口；导入错误用备份恢复或反向手工交易。
- 代码排序：不引入 symbol.sort_order，统一按 ticker 升序、再按 id 升序。
