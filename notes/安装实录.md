# 从零安装实录

日期：2026-10-29。机器：macOS，Node v25.6.1，npm 11.9.0，Docker 29.3.1。

## 本地

```bash
cd /Users/you/NO/ballast
npm ci
npm run build
npm test
npm start
```

实际结果：

- `npm ci`：使用仓库根 lockfile，安装 server + web 依赖成功。
- `npm run build`：Vite 8.3.5 构建成功，产物 `web/dist` 约 266KB JS / 14KB CSS（gzip 80KB / 3.5KB）。
- `npm test`：28 项通过，0 跳过。
- `npm start`：监听 `127.0.0.1:8787`，打开总览页。
- `node:sqlite` 在 Node 25 会打印 `ExperimentalWarning`；脚本用 `--disable-warning=ExperimentalWarning` 隐藏，功能正常。Node 24 LTS 同样支持。

## Docker

```bash
docker build -t ballast:0.1.0 .
docker run --rm -p 127.0.0.1:8787:8787 -e BALLAST_DEMO=1 ballast:0.1.0
```

- 构建使用 `node:24-bookworm-slim`，多阶段；运行镜像不含 dev 依赖。
- 端口只发布到宿主机回环；容器内 `BALLAST_HOST=0.0.0.0`、`BALLAST_DOCKER=1`。
- 数据目录 `/data` 由 `node` 用户拥有。

## 首次使用路径

1. 打开 `http://127.0.0.1:8787`，进入设置页。
2. 组合名“长期组合”，币种 CNY，模板“三分类”。
3. 持仓页“新增代码” `510300`，每手 100 份，价格 4.123。
4. 再新增 `511010`、`511880`，补足三个分类。
5. 新增买入，或 `BALLAST_DEMO=1` 直接看示例。
6. 总览输入 1,000，生成计划；计划页选账户执行。
